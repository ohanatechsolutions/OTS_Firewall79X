# Contributing

Preserve all 79 catalog IDs and do not promote a capability to operational without real health evidence. Put limitations in the UI and LAYER_COVERAGE.md. Never count a detection as an OTS block without a confirmed enforcing action. Use bounded input, least privilege, reversible settings, and current test results. No forced branch rewrites or unrelated removals.

Run core regressions and Windows CI. Mutation tests run only in disposable environments. Update the coverage table, SBOM, release notes, and known limitations with each behavior change. Use draft PRs for work that cannot yet meet its acceptance gates.
