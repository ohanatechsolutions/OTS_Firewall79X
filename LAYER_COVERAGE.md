Unknown settings are never called enabled, and full ASLR, disk encryption, vulnerability assessment and password policies remain out of scope for this check.

## Follow-up — Feodo C2 observation (2026-10-27)

Layer 5 now compares sampled established TCP destinations with a strictly validated *recommended* public Feodo Tracker C2 IPv4 list, if current; layer 63 reports source age, errors and freshness. Neither feature adds a firewall rule or replaces a packet-level, signed-feed blocking engine; the mandatory full requirements are not complete. Tests include invalid, private, missing-timestamp and stale entries.


## Follow-up — conditional file-read telemetry (2026-10-27)

- Layer 31 now correlates **real** Security Event ID 4663 file-read access against supported Chromium/Firefox credential/session storage paths, highlighting unexpected reading processes without reading credentials. Conditional operation requires existing successful File System auditing and suitable SACLs.
- Layer 34 now correlates 64 distinct SACL-audited files read by one process within one minute, with bounded in-memory SHA-256 path fingerprints and alert suppression. A read burst is **not** proof of copying or exfiltration, and does not inspect network payloads.
- On Windows installations without object-access policy and file SACLs, these layers truthfully remain unavailable. They are **not** certified as meeting their full security specification.


## Follow-up — DNS observation and screen fit

Layer 8 now watches actual Windows DNS Client Event 3008 results where the event channel is enabled, tracking suspicious public-to-local address transitions in a bounded privacy-preserving cache. This is an **alert-only heuristic**, not DNS blocking; channel absence and unobserved responses remain unavailable. Window startup dimensions now adapt to the Windows working area so the dashboard fits smaller laptop displays. Neither addition meets a complete production security acceptance gate.


## Extended host audits — SSH and Docker exposure (2026-10-27)

- **Layer 40:** Windows TCP listeners for common container API ports 2375/2376 are classified for local-only vs network bindings, and a possible plaintext management endpoint produces an alert; no remote connection or firewall modification is attempted. This remains a partial exposure audit.
- **Layer 42:** Windows OpenSSH global sshd_config settings now use first-value parsing and explicitly refuse hardening claims where Include, Match, missing or unknown directives could affect effective settings. No SSH settings are modified. Effective sshd -T, authentication method behavior and authorized-key ACLs still need verification.
